## Decisions after reviewing the agent memo

- Retain the fixed CX23 and Cloudflare direction. Managed-hosting alternatives researched before the user's clarification do not drive this plan.
- Use verified price components and a formula instead of presenting the agent's conditional €7.09 estimate as the expected bill.
- Propose verified email/password rather than the agent's email-OTP preference. This avoids requiring a new delivery for each routine login; the user can choose OTP during review.
- Use an authenticated, byte-limited streaming upload endpoint for beta. Direct signed uploads can follow after their size/quota enforcement is demonstrated; do not trust a declared file size or publish a key that remains overwriteable.
- Treat RLS as optional additional protection in a server-only database design. Explicit ownership checks and two-account tests are required regardless of that choice.
- Keep five publication revisions, 30 links, 100 MB retained media per account and a 10 MB/three-minute track limit as explicit product proposals. They differ from the agent's tighter sample quotas and are not claimed to be provider limits.
- Adopt explicit suspension/media-removal bounds, checks for private framework responses, trusted proxy headers, and restore-time deletion/suspension reapplication.
- Keep exact capacity, recovery time and mobile speed as acceptance targets. They cannot be verified before the application and deployment exist.

## Remaining deployment inputs

The user confirmed Cloudflare DNS, but account settings, zone/bucket ownership, rule entitlements and credentials were not inspected. Server region, eventual stock/price, email setup, backup destination and alert recipient must be settled before hosted acceptance. Age/content policy, operating jurisdiction and moderation responsibility must be settled before inviting real users.

Only planning documentation and its explanatory chart were created. No application scaffold, dependencies, server, DNS records, provider accounts or deployment were created or changed, and no application tests or capacity measurements have been run.
